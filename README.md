# Cubie A7S 移动操作机器人开发手册

基于 **Radxa Cubie A7S**（全志 A733，2×A76 + 6×A55，NPU 3 TOPS，6GB LPDDR5）与 **ROS 2** 的移动操作机器人（麦轮底盘 + 六轴机械臂 + YOLO 视觉 + 离线语音 + 激光雷达导航）完整开发手册，单文件 HTML，浏览器直接打开即可阅读。

当前版本：**v2.2（2026-10）**

## 在线预览

`index.html` 为本手册唯一入口，开启 GitHub Pages 后可直接访问：

```
Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
```

随后访问 `https://<你的用户名>.github.io/<仓库名>/`。

仓库根目录已放置 `.nojekyll`，用于关闭 Jekyll 处理——否则以 `_` 开头的 `_shared/` 目录会被 GitHub Pages 忽略，字体与脚本全部 404。

## 本地预览

直接用浏览器打开 `index.html` 即可（所有路径均为相对路径，无需搭服务器）。

如需以服务方式预览：

```bash
python -m http.server 8765
# 浏览器访问 http://localhost:8765/index.html
```

## 硬件平台要点

- Cubie A7S 无 HDMI、无 3.5mm 音频口；视频必须走 **USB-C2（DP Alt Mode）**，音频必须走 USB 声卡
- 可供外设使用的 USB 仅 **USB-A 2.0 + USB-C2** 两个，外设 ≥3 个需带 5V 辅助供电的 Hub
- 供电为 **5V 固定输入**，不做 PD 诱骗，建议 5V/4A 以上
- 满载约 9W，必须配主动散热（散热片 + 4010 风扇）
